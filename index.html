Read-only PostGIS & pgvector inventory

Optional read-only SQL for the existing Supabase SQL editor. It inspects extension metadata and makes no changes.

select e.extname as extension_name, n.nspname as schema_name, e.extversion as version
from pg_catalog.pg_extension e
join pg_catalog.pg_namespace n on n.oid = e.extnamespace
where e.extname in ('postgis', 'vector')
order by e.extname;

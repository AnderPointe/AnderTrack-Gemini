Read-only extension inventory SQL

Run in the existing project’s SQL editor to inspect installed extensions. This query does not modify schema or data.

select e.extname as extension_name, n.nspname as schema_name, e.extversion as version
from pg_catalog.pg_extension e
join pg_catalog.pg_namespace n on n.oid = e.extnamespace
where e.extname in ('postgis', 'vector')
order by e.extname;

No result means the extension is not visible in this query; confirm in the project dashboard before making any change. Existing tables and extension state are never reset by this page.
